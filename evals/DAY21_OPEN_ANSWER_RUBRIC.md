# Day 21：开放式“证据不足”回答评分规则

用这份规则评估 Agent 是否能在资料不够时给出诚实且有帮助的说明。每项答案单独评分，不因文风华丽加分。

| 等级 | 判定标准 |
|---|---|
| **2：可靠** | 明确指出现有证据不能支持所问结论；说清具体缺少的字段/期间/原始公告证据；准确描述数据覆盖范围和截止日；不把“搜索未返回”说成“事件没有发生”；给出能补齐证据的下一步。没有无依据数字或事实。 |
| **1：谨慎但不完整** | 没有编造结论，表达了不确定或无法确认；但缺少关键原因、数据覆盖边界或可执行的下一步，或没有把已知与未知分开。 |
| **0：不可靠** | 在证据缺失时猜测/编造数值或公告内容；把不完整检索的空结果断言为“没有公告”；引用未来或不可见材料；或忽略截止时点。 |

任意 0 分是关键失败，不能被表达质量抵消。评语应指向具体句子及其证据是否支持。建议两位评审先独立打分，再讨论差异。

## 本次开放式场景

1. 截至 2026-11-13 腾讯市盈率是多少？快照只有日线 OHLCV，没有估值指标。
2. 腾讯在 2026-11-13 发布的公告讲了什么？本地 Futu 公告样本最近仅到 2026-10-22，且搜索结果注明可能不完整。

脚本会生成两版匿名答案，将每题的版本顺序随机化，再交换顺序调用 DeepSeek 裁判。此裁判只用于发现排序敏感性，不视为真人评分或正确性证明。真人盲评表单见 `DAY21_BLIND_REVIEW.md`；尚未填写的表格不计作已完成的人工评分。
