# Day 24 关键词检索基线

在 Day 23 的 **772** 块上实现可复现的关键词排名基线。本步**不**改官方 PDF、`manifest.json`、`questions.json`、`fixtures/filings.json`、`get_filings()`；**不**重切 `chunks.jsonl`；**不**调用 OpenD。

## 设计原则

1. **先过滤、再打分**：禁止对全部 772 块无差别算分。
2. **过滤维度**（与计划一致）：
   - **权限**：`allowed_symbols`（本基线固定 `HK.00700`、`HK.01698`）。
   - **标的**：从问题文本（及 gold `document_id` 仅用于解析）推断 `symbol`，再只保留该发行人块。
   - **截止时点**：`manifest.documents[].available_at <= as_of`（基线 `as_of=2026-11-19`）。
3. **故意不传 `document_id` 过滤**：同一发行人有多期 PDF（如腾讯 2025 全年 + 2026 中期）时，模拟「只知公司、不知具体公告」的路由不确定性。这是 Q3/Q4 错期的主要原因之一。
4. **打分**：在过滤后的子语料上统计词频 IDF，对块的检索字段做查询词命中加权求和。检索字段 = 块 `text` + `section_headings` + `period.labels` + `issuer.name` + `document.snapshot_reporting_period` + manifest 上的 `company` / `title_zh` / `title_en` / `reporting_period`。

实现：`fin_agent/keyword_retrieval.py`（`keyword_retrieval.v1`）。机器可读运行结果：`evals/runs/day24_keyword_baseline.json`。

## 查询分词

- 英文/数字：单词与 2 位以上数字串。
- 中文：整段 CJK 串（≤20 字）+ 预置业务标记切分（如 `收入`、`止年度`、`末期股息`、`微信`、`WeChat`、`Revenues` 等）。
- **未**做同义词扩展（如 收入↔Revenues、简繁转换、亿元↔百万元、合并月活跃↔MAU），便于如实记录同义缺口。

## 手算 Precision@5 / Recall@5（D22-Q1）

### 金标准（严格，对齐 Day 22）

- **相关块集合** \(R\)：仅证据页上的块  
  \(R = \{\texttt{tencent\_hk00700\_2025\_annual\_results:p002:c001}\}\)  
  （第 2 页摘要表，引用「收入 … 751,766」。）

### Top-5 预测集合

按 baseline 排名前 5 个 chunk_id：

1. `…:p007:c003`  
2. `…:p011:c003`  
3. `…:p008:c001`  
4. `…:p025:c001`  
5. `…:p007:c001`

### 计算

- 命中数：top5 与 \(R\) 交集为空，\(| \text{hits} | = 0\)。
- **Precision@5** \(= \frac{|\text{hits}|}{5} = \frac{0}{5} = 0.00\)
- **Recall@5** \(= \frac{|\text{hits}|}{|R|} = \frac{0}{1} = 0.00\)

### 宽松金标准（说明用，非 Day 22 官方证据页）

凡正文含**合并总收入** `751,766` 的腾讯 2025 全年块（共 5 个：`p002:c001`、`p006:c002`、`p007:c002`、`p025:c001`、`p033:c002`）。此时 top5 仅第 4 名 `p025:c001` 命中：

- Precision@5 \(= 1/5 = 0.20\)  
- Recall@5 \(= 1/5 = 0.20\)

### 同义与词面缺口（影响 Q1 及跨题）

| 缺口 | 示例 | 后果 |
|---|---|---|
| 中英指标名 | 问「收入」/ 证据 `Revenues`（Q3） | 中期英文表无中文「收入」命中 |
| 简繁 | 问简体「腾讯」/ PDF「騰訊」 | 靠 manifest `company` 补「腾讯控股」，块内繁体仍可能缺词 |
| 单位换写 | 7,518 **亿元** vs 751,766 **百万元** | 叙事块进 top5，摘要用表难靠前 |
| 经营指标用语 | 「合并月活跃账户」vs `Combined MAU` /「合併月活躍賬戶」 | Q4 金块仅排第 4 |
| 日期表述 | 「二零二六年六月三十日」vs `30 June 2026` | 英文表头分词未对齐 |
| 公司简称 | 块内无「腾讯控股」但含答案数字 | `p002` 排名低于带 manifest 公司名的段落 |
| 干扰数字 | 腾讯 751,766 vs 音乐 32,902 | Q5 靠 symbol 过滤化解；若不过滤会误召回 |

## 局限

- 无向量语义、无 RRF、无 LLM 重排。
- 同一 symbol 多期公告并存时，缺少报告期路由（`document_id` / 期间解析）会把 Q3/Q4 拉向错误报告期。
- IDF 与词面匹配无法区分「分部收入」与「总收入」行。
- 下一步（Day 25+）才适合 embedding 与同义词表。
